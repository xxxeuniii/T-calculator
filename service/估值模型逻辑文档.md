# 股票估值模型逻辑文档（含后端实现）

## 一、模型概述

本估值模型是一个基于财务数据分析的股票估值系统，采用**重资产/轻资产分类判定** + **复合增长率预测** + **PS/PE估值法**的三层架构。后端采用**纯函数层与数据层分离**的设计，确保估值公式可测试、可复用。

## 三、核心算法详解（纯函数层）

### 3.1 纯函数设计原则

| 特性 | 说明 |
|------|------|

### 3.2 估值方法判定

```python
def calculate_valuation_method(
    invest_real_estate: float,  # 投资性房地产（亿元）
    cip: float,                  # 在建工程（亿元）
    fix_assets: float,           # 固定资产（亿元）
    total_assets: float          # 总资产（亿元）
) -> Dict[str, Any]:
    """
    规则：
    - 重资产比例 = (投资性房地产 + 在建工程 + 固定资产) / 总资产 × 100%
    - 重资产比例 > 40% → 市盈率估值法（PE）
    - 否则 → 市销率估值法（PS）
    """
    if total_assets == 0:
        return {
            'asset_ratio': 0.0,
            'asset_type': '无法判断',
            'valuation_method': '无法判断'
        }
    
    heavy_asset_sum = invest_real_estate + cip + fix_assets
    asset_ratio = round((heavy_asset_sum / total_assets) * 100, 2)
    
    if asset_ratio > 40:
        return {
            'asset_ratio': asset_ratio,
            'asset_type': '重资产',
            'valuation_method': '市盈率估值法'
        }
    else:
        return {
            'asset_ratio': asset_ratio,
            'asset_type': '轻资产',
            'valuation_method': '市销率估值法'
        }
```

### 3.3 复合增长率计算

#### 3.3.1 CAGR（复合年增长率）

```python
def calculate_cagr(start_value: float, end_value: float, years: int) -> float:
    """
    CAGR = (end/start)^(1/years) - 1
    
    例如：5年内从100亿增长到200亿
    CAGR = (200/100)^(1/5) - 1 = 14.87%
    """
    if start_value <= 0 or end_value <= 0 or years <= 0:
        return 0.0
    return ((end_value / start_value) ** (1 / years) - 1) * 100
```

#### 3.3.2 综合复合增速

```python
def calculate_composite_growth(
    history_revenues: List[float],          # 历年营收（亿元）
    history_net_profits: List[float],       # 历年净利润（亿元）
    history_revenue_growths: List[float],   # 历年营收同比(%)
    history_net_profit_growths: List[float],# 历年净利润同比(%)
    latest_revenue_yoy: float = 0,          # 最新营收同比(%)
    latest_net_profit_yoy: float = 0        # 最新净利润同比(%)
) -> Dict[str, Any]:
    """
    综合复合增速 = (历史增速 × 历史权重 + 最新同比) / (历史权重 + 1)
    
    历史权重 = 历史数据点数，使最新数据的权重约为1/(n+1)
    """
    # 五年 CAGR
    five_year_avg_revenue = calculate_cagr(
        history_revenues[0], history_revenues[-1], len(history_revenues) - 1
    ) if len(history_revenues) >= 2 else 0.0
    
    # 五年平均增长率
    five_year_avg_revenue_growth = (
        sum(history_revenue_growths) / len(history_revenue_growths)
        if history_revenue_growths else 0.0
    )
    
    # 综合复合增速计算
    history_weight = len(history_revenue_growths)
    composite_revenue_growth = (
        (five_year_avg_revenue_growth * history_weight + latest_revenue_yoy)
        / (history_weight + 1)
    )
    
    return {
        'five_year_avg_revenue': round(five_year_avg_revenue, 2),
        'five_year_avg_revenue_growth': round(five_year_avg_revenue_growth, 2),
        'composite_revenue_growth': round(composite_revenue_growth, 2),
        # ... 其他字段
    }
```

### 3.4 财务预测

```python
def calculate_forecast(
    revenue_last_year: float,              # 去年营收（亿元）
    net_profit_last_year: float,           # 去年净利润（亿元）
    composite_revenue_growth: float,       # 综合营收增速(%)
    composite_net_profit_growth: float     # 综合净利润增速(%)
) -> Dict[str, Any]:
    """
    预测公式：
    forecast = last_year * (1 + growth_rate / 100)
    
    例如：去年营收100亿，增速10% → 今年预测110亿
    """
    forecast_revenue_current = revenue_last_year * (1 + composite_revenue_growth / 100)
    forecast_net_profit_current = net_profit_last_year * (1 + composite_net_profit_growth / 100)
    
    return {
        'forecast_revenue_current': round(forecast_revenue_current, 2),
        'forecast_net_profit_current': round(forecast_net_profit_current, 2),
    }
```

### 3.5 目标价计算

```python
def calculate_forecast_price(
    total_mv: float,                       # 总市值（亿元）
    total_share: float,                    # 总股本（亿股）
    close_price: float,                    # 当前股价（元）
    eps_last_year: float,                  # 去年每股收益（元）
    revenue_last_year: float,              # 去年营收（亿元）
    forecast_revenue_current: float,       # 预测营收（亿元）
    forecast_net_profit_current: float,    # 预测净利润（亿元）
    valuation_method: str                  # 估值方法
) -> Dict[str, Any]:
    """
    PS法（轻资产）：
        ps_ratio = 总市值 / 去年营收
        ps_price = (ps_ratio × 预测营收) / 总股本
    
    PE法（重资产）：
        pe_ratio = 当前股价 / 去年每股收益
        pe_price = (预测净利润 × pe_ratio) / 总股本
    """
    # PS估值
    ps_price_current = 0.0
    if revenue_last_year > 0 and total_share > 0:
        ps_ratio = total_mv / revenue_last_year
        ps_price_current = (ps_ratio * forecast_revenue_current) / total_share
    
    # PE估值
    pe_price_current = 0.0
    if eps_last_year > 0 and total_share > 0:
        pe_ratio = close_price / eps_last_year
        pe_price_current = (forecast_net_profit_current * pe_ratio) / total_share
    
    # 根据资产类型选择最终结果
    final_price_current = (
        ps_price_current if valuation_method == '市销率估值法' else
        pe_price_current if valuation_method == '市盈率估值法' else 0.0
    )
    
    return {
        'ps_price_current': round(ps_price_current, 2),
        'pe_price_current': round(pe_price_current, 2),
        'final_price_current': round(final_price_current, 2),
    }
```

### 3.6 极值过滤

```python
def apply_extreme_filter(growth_rates: List[float]) -> Dict[str, Any]:
    """
    极值过滤规则：
    - 极差（max - min）> 300% 时，去头去尾取平均
    - 数据点 ≤ 2 时不应用过滤
    
    目的：防止极端值（如疫情期间暴增/暴跌）影响估值准确性
    """
    if len(growth_rates) <= 2:
        avg = sum(growth_rates) / len(growth_rates)
        return {
            'filtered_growth': round(avg, 2),
            'filter_applied': False,
            'extreme_gap': abs(growth_rates[-1] - growth_rates[0]),
        }
    
    min_rate = min(growth_rates)
    max_rate = max(growth_rates)
    extreme_gap = abs(max_rate - min_rate)
    
    if extreme_gap > 300:
        # 去头去尾
        filtered = sorted(growth_rates)[1:-1]
        return {
            'filtered_growth': round(sum(filtered) / len(filtered), 2),
            'filter_applied': True,
            'extreme_gap': round(extreme_gap, 2),
        }
    
    return {
        'filtered_growth': round(sum(growth_rates) / len(growth_rates), 2),
        'filter_applied': False,
        'extreme_gap': round(extreme_gap, 2),
    }
```

### 3.7 亏损标的判断

```python
def check_loss_stock(
    net_profits: List[float],   # 扣非净利润列表（亿元）
    revenues: List[float]       # 营收列表（亿元）
) -> Dict[str, Any]:
    """
    基于退市规则的亏损判断：
    
    规则1：最近1年扣非净利润 < 0 且 营收 < 1亿元 → *ST
    规则2：连续2年扣非净利润 < 0 → ST
    规则3：连续3年扣非净利润 < 0 → 退市
    
    优先级：规则1 > 规则3 > 规则2
    """
    if not net_profits:
        return {'is_chronic_loss': False, 'loss_reason': '', 'risk_level': ''}
    
    latest_net_profit = net_profits[-1]
    latest_revenue = revenues[-1] if revenues else 0
    
    # 规则1：*ST
    if latest_net_profit < 0 and latest_revenue < 1:
        return {
            'is_chronic_loss': True,
            'loss_reason': '最近1个会计年度扣非净利润为负且营收＜1亿元',
            'risk_level': '*ST'
        }
    
    # 规则3：退市（优先级高于ST）
    if len(net_profits) >= 3 and all(p < 0 for p in net_profits[-3:]):
        return {
            'is_chronic_loss': True,
            'loss_reason': '连续3年扣非净利润为负，触发退市流程',
            'risk_level': '退市'
        }
    
    # 规则2：ST
    if len(net_profits) >= 2 and all(p < 0 for p in net_profits[-2:]):
        return {
            'is_chronic_loss': True,
            'loss_reason': '连续2年扣非净利润为负值',
            'risk_level': 'ST'
        }
    
    return {'is_chronic_loss': False, 'loss_reason': '', 'risk_level': ''}
```

## 四、业务流程层

### 4.1 估值流程执行顺序

```
┌─────────────────────────────────────────────────────────────────────┐
│                      估值计算执行流程                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  步骤01: 估值方法判定                                              │
│    └── 读取资产负债表数据                                          │
│    └── 计算重资产比例                                              │
│    └── 判定使用PE法还是PS法                                        │
│                          ↓                                        │
│  步骤02: 复合增长率计算                                            │
│    └── 读取历史财务数据（最多10年）                                 │
│    └── 读取最新季度财报                                            │
│    └── 计算五年CAGR和平均增速                                      │
│    └── 综合历史增速与最新同比                                        │
│                          ↓                                        │
│  步骤06: 极值过滤（可选前置步骤）                                   │
│    └── 检测增长率数据是否存在极端值                                 │
│    └── 若极差>300%则去头去尾取平均                                  │
│                          ↓                                        │
│  步骤03: 财务预测                                                  │
│    └── 获取去年营收/净利润                                          │
│    └── 应用复合增长率预测当年数据                                    │
│                          ↓                                        │
│  步骤04: 目标价计算                                                │
│    └── 获取当前市场数据（市值、总股本、股价）                        │
│    └── 根据估值方法计算目标价                                       │
│                          ↓                                        │
│  步骤05: 亏损判断（并行步骤）                                       │
│    └── 判断是否存在退市风险                                        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 八、核心设计特点

| 特点 | 说明 |
|------|------|
| **纯函数分离** | 估值算法与数据层解耦，易于测试和回测 |
| **资产分类** | 自动识别重资产/轻资产，选择合适估值方法 |
| **动态权重** | 历史数据与最新数据加权，平衡稳定性与时效性 |
| **极值过滤** | 防止极端值影响估值准确性 |
| **风险评估** | 基于退市规则的亏损判断 |
| **可扩展性** | 新增估值方法只需添加新的纯函数 |
