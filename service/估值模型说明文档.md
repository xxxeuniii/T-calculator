# 股票估值模型逻辑文档

## 一、模型概述

本估值模型是一个基于财务数据分析的股票估值系统，核心采用**重资产/轻资产分类判定** + **复合增长率预测** + **PS/PE估值法**的三层架构，旨在为投资者提供科学、可量化的股票估值参考。

---

## 二、估值流程总览

```
┌─────────────────────────────────────────────────────────────────────┐
│                      估值模型完整流程                              │
├─────────────────────────────────────────────────────────────────────┤
│  1. 数据采集                                                      │
│     └── 股票基本信息、财务报表、市场数据                            │
│                          ↓                                        │
│  2. 资产类型判定                                                  │
│     └── 固定资产占比 > 40% → 重资产 → PE估值法                     │
│     └── 固定资产占比 ≤ 40% → 轻资产 → PS估值法                     │
│                          ↓                                        │
│  3. 复合增长率计算                                                │
│     └── 五年平均增速 + 最新季度增速 → 综合复合增长率                │
│                          ↓                                        │
│  4. 未来数据预测                                                  │
│     └── 基于复合增长率预测下一年营收/净利润                        │
│                          ↓                                        │
│  5. 目标价计算                                                    │
│     └── PE法: 预测净利润 × PE倍数 / 总股本                        │
│     └── PS法: 预测营收 × PS倍数 / 总股本                          │
│                          ↓                                        │
│  6. 风险评估                                                      │
│     └── 极值过滤、亏损判断、操作建议                              │
└─────────────────────────────────────────────────────────────────────┘
```

## 三、核心模块详解

### 3.1 资产类型判定模块

#### 判定逻辑

| 指标 | 计算公式 | 判定阈值 |
|------|----------|----------|
| 固定资产占比 | (投资性房地产 + 在建工程 + 固定资产) / 总资产 × 100% | > 40% 为重资产 |

#### 判定规则

```python
# 重资产判定条件（估值方法判定核心逻辑）
asset_ratio = (invest_real_estate + cip + fix_assets) / total_assets * 100

if asset_ratio > 40:
    is_heavy_asset = True
    valuation_method = "市盈率估值法"  # PE法
else:
    is_heavy_asset = False
    valuation_method = "市销率估值法"  # PS法
```

#### 数据来源

| 字段 | 说明 | 数据来源 |
|------|------|----------|
| `invest_real_estate` | 投资性房地产（亿元） | 资产负债表 |
| `cip` | 在建工程（亿元） | 资产负债表 |
| `fix_assets` | 固定资产（亿元） | 资产负债表 |
| `total_assets` | 总资产（亿元） | 资产负债表 |

---

### 3.2 复合增长率计算模块

#### 计算逻辑

复合增长率采用**五年平均增速**与**最新季度增速**的加权综合：

```python
# 综合复合增长率计算
composite_revenue_growth = (
    five_year_avg_revenue_growth * 0.6 +  # 历史长期趋势权重 60%
    latest_tr_yoy * 0.4                    # 最新增速权重 40%
)

composite_net_profit_growth = (
    five_year_avg_net_profit_growth * 0.6 +
    latest_netprofit_yoy * 0.4
)
```

#### 数据指标

| 指标 | 说明 |
|------|------|
| `five_year_avg_revenue` | 五年平均营收（亿元） |
| `five_year_avg_revenue_growth` | 五年平均营收增长率（%） |
| `five_year_avg_net_profit` | 五年平均净利润（亿元） |
| `five_year_avg_net_profit_growth` | 五年平均净利润增长率（%） |
| `latest_tr_yoy` | 最新季度营收同比增长率（%） |
| `latest_netprofit_yoy` | 最新季度净利润同比增长率（%） |

---

### 3.3 未来数据预测模块

#### 预测公式

基于综合复合增长率预测当前财年的营收和净利润：

```python
# 预测当前财年数据
forecast_revenue_current = revenue_last_year * (1 + composite_revenue_growth / 100)
forecast_net_profit_current = net_profit_last_year * (1 + composite_net_profit_growth / 100)
```

#### 预测时间逻辑

| 报告期 | 预测财年 |
|--------|----------|
| 一季度（1-3月） | 报告年份 |
| 中报（4-6月） | 报告年份 |
| 三季度（7-9月） | 报告年份 |
| 年报（10-12月） | 报告年份 |

---

### 3.4 目标价计算模块

#### PE估值法（重资产适用）

**适用场景**：传统制造业、基础设施、资源类企业

```python
# PE估值法公式
pe_price_current = (forecast_net_profit_current * 10000) * pe_ratio / total_share
```

**参数说明**：

| 参数 | 说明 | 单位 |
|------|------|------|
| `forecast_net_profit_current` | 预测净利润 | 亿元 |
| `pe_ratio` | 行业平均市盈率 | 倍 |
| `total_share` | 总股本 | 亿股 |

#### PS估值法（轻资产适用）

**适用场景**：互联网、科技服务、平台型企业

```python
# PS估值法公式
ps_price_current = (forecast_revenue_current * 10000) * ps_ratio / total_share
```

**参数说明**：

| 参数 | 说明 | 单位 |
|------|------|------|
| `forecast_revenue_current` | 预测营收 | 亿元 |
| `ps_ratio` | 行业平均市销率 | 倍 |
| `total_share` | 总股本 | 亿股 |

#### 最终预测价

```python
# 根据资产类型选择估值结果
if valuation_method == "市盈率估值法":
    final_price_current = pe_price_current
else:
    final_price_current = ps_price_current
```

### 3.5 风险评估模块

#### 极值过滤

对估值结果进行合理性校验：

| 过滤条件 | 说明 |
|----------|------|
| 股价下限 | 预测价 > 0 |
| 股价上限 | 预测价 < 当前价 × 5（防止过度乐观） |
| 增长率限制 | 复合增长率在合理区间内 |

#### 亏损判断

| 指标 | 判断标准 |
|------|----------|
| 净利润亏损 | 最新季度净利润 < 0 |
| 连续亏损 | 连续多个季度净利润 < 0 |
| 营收下滑 | 营收同比增长率 < 0 |

#### 上涨空间计算

```python
# 上涨空间 = (预测价 - 当前价) / 当前价 × 100%
price_space = (predicted_price - close_price) / close_price * 100
```

**空间评级**：

| 上涨空间 | 评级 |
|----------|------|
| ≥ 50% | 强烈推荐 |
| 30% - 50% | 推荐 |
| 10% - 30% | 观望 |
| < 10% | 不推荐 |

## 七、估值模型特点

| 特点 | 说明 |
|------|------|
| **资产分类** | 自动识别重资产/轻资产，选择合适估值方法 |
| **动态权重** | 五年历史与最新季度数据加权，平衡稳定性与时效性 |
| **行业对标** | 采用行业平均PE/PS倍数，确保可比性 |
| **风险控制** | 极值过滤、亏损判断，避免极端估值 |
| **可视化** | 多维度数据卡片展示，直观易懂 |

---

## 八、使用建议

1. **数据更新频率**：建议每季度财报发布后更新数据
2. **估值局限性**：本模型为参考工具，实际投资需结合市场情绪、政策变化等因素
3. **适用范围**：适用于A股上市公司，不适用于未盈利或特殊行业企业
4. **风险提示**：投资有风险，估值结果仅供参考，不构成投资建议
