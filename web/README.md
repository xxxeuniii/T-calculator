# trade-tool

一个用于计算股票 T+0 交易和合约移动止盈止损的计算器应用。

## 功能特性

### 📈 股票计算器
- **正T交易**：先卖出后接回，降低持仓成本
- **反T交易**：先买入后卖出，降低持仓成本
- 自动计算价差收益、佣金、印花税
- 显示做T后的新成本价和成本降低金额
- 支持成本价自动回填卖出价和接回价
- 股数和价格步进器，便于快速输入

### 📊 合约计算器
- **做多/做空**：支持两种交易方向
- **移动止盈止损**：根据回调率和激活价格计算预计止盈价
- 快速设置常用回调率（0.1%、0.3%、0.5%、1%）
- 自动估算预期盈亏金额

### 📋 历史记录
- 保存所有交易记录
- 支持从历史记录快速回填数据
- 一键清空历史记录

### 📱 响应式设计
- **移动端**：单列布局，适合手机屏幕
- **桌面端**：两列布局，输入面板和结果面板并排显示

## 使用说明

### 股票 T+0 交易
1. 输入持仓成本价
2. 设置持仓股数和做T股数
3. 输入卖出价和接回价（或使用步进器调整）
4. 系统自动计算收益和新成本价
5. 点击"确认并存入历史"保存记录

### 合约移动止盈止损
1. 选择交易方向（做多/做空）
2. 输入成本价、回调率、数量和激活价格
3. 系统自动计算预计止盈价
4. 点击"确认并存入历史"保存记录

## 费率说明

- **股票佣金**：万分之三，买卖双向，单笔最低 5 元
- **印花税**：卖出金额的 0.05%
